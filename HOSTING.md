# Hosting Notes — Shreya Raut Portfolio

This project is a self-contained static HTML, CSS, JavaScript, and image portfolio (`index.html`).

## Local Preview

From the project folder:

```bash
npx serve .
# or: python -m http.server 8080
```

Then open `http://localhost:3000` (or `http://localhost:8080`).

## Production Deployment

Deploy the project root (`index.html`, `assets/`, `images/`, `fonts/`) to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
